# Atlas — Villes — ratissage 1.1 Nordiques
**Snapshot : 1er janvier 1945, 00:00**

Ce lot poursuit le ratissage des villes après France / Benelux / îles Britanniques.

## Périmètre
Danemark, Îles Féroé, Norvège, Suède, Finlande, Islande.

**56 villes proposées.**

## Principe
La ville n'est pas sélectionnée parce qu'elle existe ou parce qu'elle sera importante plus tard. Elle est sélectionnée parce qu'elle a **déjà au 01/01/1945** un rôle structurant pour les flux physiques de l'Atlas : capitale, port, rail, ferry, frontière, industrie, minerai, logistique militaire, aviation, navigation côtière, etc.

Comme pour Reims, **aucun rôle futur n'est anticipé**.

## Cas particulièrement importants

### Danemark
- Copenhague A.
- Aarhus, Odense, Aalborg, Esbjerg B.
- Korsør/Nyborg sont conservées comme villes C parce qu'avant la liaison fixe le Grand Belt est un passage ferroviaire-ferry structurant.
- Padborg C = frontière ferroviaire allemande.
- Fredericia C, avec audit possible pour B.

### Norvège
- Narvik B est indispensable : minerai suédois + Ofotbanen + port stratégique.
- Trondheim B : port + rail + navigation côtière.
- Stavanger B : le Sørlandsbanen continu vers Oslo est achevé en 1944.
- Kirkenes C : ville-frontière, libérée en 1944, très détruite.
- Hammerfest C est volontairement conservée bien qu'évacuée/détruite : la **rupture d'un nœud de flux** est une information Atlas.

### Suède
- Stockholm A ; Göteborg/Malmö/Helsingborg/Trelleborg/Luleå/Kiruna en B.
- Kiruna + Luleå + Narvik forment déjà un futur excellent cas de chaîne `mine → rail → port`.
- Haparanda C forme un couple de frontière avec Tornio.
- Karlskrona C = base navale.

### Finlande
- Helsinki A.
- Turku/Tampere/Oulu/Kotka B.
- Hanko C : port d'hiver + rail.
- Tornio C face à Haparanda.
- Rovaniemi C : nœud ferroviaire détruit pendant le retrait allemand ; sa perturbation est pertinente.
- Kouvola C : carrefour ferroviaire.
- Vyborg/Viipuri **non inclus ici** : au Snapshot 0 la ville est soviétique, donc elle ira dans le lot Est/URSS pour éviter deux entités concurrentes.

### Islande
- Reykjavík A : principal port et nœud logistique allié.
- Akureyri B : principal port secondaire du nord.
- Keflavík C : terrain aérien américain ouvert en 1943, route transatlantique.
- Seyðisfjörður C : port allié de transbordement/ravitaillement.
- Hvalfjörður n'est pas une ville : attendre la future couche bases/ports.

### Féroé
Tórshavn B : capitale/port et centre administratif pendant la séparation de fait du Danemark occupé.
