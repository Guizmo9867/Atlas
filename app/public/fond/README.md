# Fond de carte physique

Données **Natural Earth 1:10m** (domaine public, https://www.naturalearthdata.com), sans frontières politiques ni noms modernes :
terres (+ petites îles), lacs, fleuves. Découpées sur l'emprise Eurasie (-30°/15°N → 180°/85°N), coordonnées arrondies à 4 décimales (~10 m).

C'est **le même trait de côte** que celui utilisé pour découper les territoires historiques (`outils/geo/`) : fond et territoires se superposent exactement.
Lacs et fleuves sont dessinés **au-dessus** des territoires.
