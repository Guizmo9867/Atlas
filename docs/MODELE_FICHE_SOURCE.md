# Fiche de source (à faire écrire par Ether dans le chat, après avoir discuté d'une source)

**Le plus simple (depuis le 06/10/2026)** : dans `00_SOURCES_A_VALIDER.html`, sur la fiche de la source, coller la fiche d'Ether en entier dans la case « Fiche d'Ether » puis cliquer « ✓ Valider avec la fiche d'Ether ». La page sait déjà de quelle source il s'agit (pas besoin du source_id) et lit la décision dans la ligne « Décision : ». Ne pas oublier ensuite le bouton 💾 « Enregistrer mes décisions dans le dossier Atlas ».

Autre possibilité : une fiche par source dans un fichier. On peut en mettre plusieurs dans le même fichier. Enregistrer le fichier (.md ou .txt) dans le dossier
**Atlas du Bureau → `05_fiches_sources/`**. Claude le lit au réveil suivant et reporte la décision au registre.
Garder les mots avant les deux-points exactement comme ci-dessous.

```
source_id : src-xxxx (l'identifiant de la source dans 00_SOURCES_A_VALIDER.md)
Décision : Ça prouve | Prouve pour 1945 (la suite plus tard) | Ne prouve pas | Lien mort
Ce qui est prouvé : une à trois phrases en français (ce que la source dit vraiment, pour la ville et le rôle concernés)
Citation exacte : le passage recopié mot pour mot, dans la langue d'origine
Où le lire : page, paragraphe, numéro de capture…
Liens : l'adresse de la page (et d'autres liens qui prouvent la même chose, s'il y en a)
Suite plus tard : (facultatif) ce que la source dit d'après le 01/01/1945, à reprendre plus tard dans la chronologie
Vu par Guizmo : oui (j'ai vu le passage sur la page moi-même) | non
Ce que j'ai appris : (facultatif) en quelques mots
```

Attention : une IA de chat peut se tromper ou inventer une citation. « Vu par Guizmo : oui » veut dire que tu as retrouvé
la citation sur la vraie page (par exemple avec Ctrl+F). C'est ce qui fait la valeur de ta validation.
